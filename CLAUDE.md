### Coding Standards
The application must STRICTLY meet these requirements:
- Use C++ with latest stable standard and optimization for size and speed
- Use multithreads so the interface does not freeze
- Source code files no longer than 500 lines
- Build correctly with Windows Build system or Visual Studio Community
- Produce a single portable EXE file with no dependencies other than the operating system DLLs
- Respect the latest MCP standard by default but fall back to a previous one if the MCP is older
